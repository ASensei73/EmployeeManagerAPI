# 👥 EmployeeManagerAPI

API REST empresarial para la gestión de empleados.  
Desarrollada con **Java + Spring Boot + MySQL**.

---

## 🚀 Tecnologías

- Java 21
- Spring Boot  
- Spring Web  
- Spring Data JPA  
- MySQL  

---

## 📘 Funcionalidades

- CRUD de empleados  
- Gestión de cargos  
- Gestión de salarios  
- Búsqueda por ID  

---

## 📂 Estructura del proyecto

- **controller** — Endpoints REST  
- **service** — Lógica de negocio  
- **repository** — Acceso a datos con JPA  
- **entity** — Modelos de base de datos  

---

## 🗄️ Base de datos

Tabla principal: **employees**

Campos:

- id  
- nombre  
- apellido  
- email  
- telefono  
- salario  
- cargo
